# PV-Phenology-China
Data and code for the paper: Vegetation Phenological Responses to Photovoltaic Power Plants in China.

This repository contains the core dataset and reproduction code for our study on the ecological impacts of photovoltaic (PV) power plants on dryland vegetation phenology. 

By utilizing the **TabPFN** algorithm and **SHAP** (SHapley Additive exPlanations) values, this repository provides a fully transparent and reproducible workflow to reveal how baseline environmental factors drive phenological shifts (SOS, EOS, LOS) following PV plant construction.

## 📂 Repository Structure

All files are placed in the root directory for a plug-and-play reproduction experience.

### 1. Code Scripts
* `Train_TabPFN_and_Extract_SHAP.py`: The core machine learning pipeline. It uses GroupKFold cross-validation to train the TabPFN model and extracts SHAP values to explain the impacts of baseline environmental drivers.
* `TabPFN_Model_and_Plotting.py`: Script to generate the SHAP summary scatter plots, visualizing the positive/negative impacts of each feature on phenological metrics.
* `Plot_SHAP_RoseChart.py`: Script to calculate and visualize the relative contributions (%) of each environmental driver using a Nightingale rose chart.

### 2. Datasets (CSV)
The repository includes 12 `.csv` files containing the environmental feature values and their corresponding SHAP values, categorized by three phenological metrics (SOS, EOS, LOS) and two spatial zones (PV Zone and Buffer/Control Zone).
* `Feature_Values_[Metric]_[Zone].csv`: The 13 baseline environmental driving factors.
* `SHAP_Values_[Metric]_[Zone].csv`: The corresponding SHAP values generated by the TabPFN explainer.
